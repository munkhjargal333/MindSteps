Хувь хүний хөгжлийн систем
Манай систем нь өдийг хүртэл дэлхийд зах замбараагүй мэдээллүүдийг ялган ангилж
хэрэглэгчийг өөрийгөө тодорхойлоход нь тусалж өөрт нь хэрэгтэй мэдээлэлээр хангахаар
ажиллана. Ингэхдээ хэрэглэгчид хүнд биш, хэт хийсвэр биш, туршиж ойлгож мэдэж авч 
үлдэхэд шаардлагатай багахан багахан заавар зөвөлгөөг өгнө өө.

хэрэглэгч өдрийн тэмдэглэл, өөрийн үнэт зүйлийг тодорхойлох, сэтгэл хөдлөлийн бичлэг гэх зэргийг
ашиглаж хэрэглэгчийн түвшинг AI ийн тусламжтайгаар тодорхойлно.

Зорилт

төлөв буюу hawkins(ухамсрын онол) * maslow +80 хүснэгт бүхий table
AI-ийн гүйцэтгэх үүрэг  мэдээлэл (sql) мэдээллийг promt ашиглан аливаа зүйлийн төлөвийн тодорхойлох

1. Сургалтын мэдээлэл цуглуулж AI ийн тусламжтайгаар төлөв боловсруулах
2. Хэрэглэгчийн мэдээлэл цуглуулж AI ийн тусламжтайгаар төлөв боловсруулах
3. Хэрэглэгчийн түвшин буюу gamification хэрэгжүүлэх
4. Хэрэглэгчийн төлөвд шаардлагатай мэдээлүүдийг санал болгох
